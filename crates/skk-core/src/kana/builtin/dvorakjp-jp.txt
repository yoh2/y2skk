# ────────────────────────────────────���────────────────────────
# DvorakJP contraction shortcuts
#
# After a consonant state, a special second key gives a common
# two-mora combination:
#   :  →  consonant_a + い   (e.g. k: = かい)   * JP: ':' on US
#   ,  →  consonant_o + う   (e.g. k, = こう)
#   .  →  consonant_e + い   (e.g. k. = けい)
#   ;  →  consonant_a + ん   (e.g. k; = かん)
#   q  →  consonant_o + ん   (e.g. kq = こん)
#   j  →  consonant_e + ん   (e.g. kj = けん)
#   k  →  consonant_u + ん   (e.g. ck = くん)
#   x  →  consonant_i + ん   (e.g. kx = きん)
#
# Omitted slots where they conflict with existing entries:
#   k+k (くん): conflicts with double-consonant っ
#   j+j (じぇん): conflicts with double-consonant っ
#   n+; (なん): conflicts with ん
#   z+, (ぞう): conflicts with ‥
#   z+. (ぜい): conflicts with …
#   z+j (ぜん): conflicts with ↓
#   z+k (ずん): conflicts with ↑
# ─────────────────────────────────────────────────────────────
